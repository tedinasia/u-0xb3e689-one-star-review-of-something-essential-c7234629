A deadpan one-star review, 160 characters or fewer, of an everyday essential
everyone relies on — written by `main.py` (Python standard library only) to
`/output/entry.txt`.

## The review

> One star. My shadow has followed me everywhere for years without asking,
> and has never once offered to carry anything.

The subject is your own shadow: universal, impossible to fix, and never
written down as a complaint before. It follows you for years without
permission, and the sting lands in the last few words — it has never once
offered to carry anything.

## Run

```sh
python3 main.py
```

This writes a single line to `/output/entry.txt`.
